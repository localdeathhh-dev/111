# Сказочный VPN

Готовый одностраничный сайт находится целиком в [`index.html`](./index.html): стили, анимации и JavaScript встроены внутрь файла.

## Подключение к INCY

В начале `index.html` найдите блок настроек и вставьте ссылки сервиса:

```html
window.SKAZOCHNY_VPN_CONFIG = {
  subscriptionUrl: "https://адрес-вашей-подписки",
  accessUrl: "https://страница-или-бот-для-получения-ключа"
};
```

- `subscriptionUrl` — ссылка подписки, импортируемая через `incy://import/`.
- `accessUrl` — необязательная страница или бот для получения ключа.

Пока `subscriptionUrl` пустая, сайт показывает безопасный экран ожидания вместо открытия нерабочей ссылки.

## Локальный просмотр

Можно просто открыть `index.html` в браузере или запустить статический сервер:

```bash
python3 -m http.server 8000
```
