# Сказочный VPN

Минималистичный motion-лендинг бесплатного VPN-сервиса с импортом подписки в INCY.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Подключение INCY

1. Скопируйте `.env.example` в `.env`.
2. Укажите реальную ссылку подписки в `VITE_SUBSCRIPTION_URL`.
3. При необходимости укажите `VITE_ACCESS_URL` — страницу или Telegram-бота, где пользователь может получить доступ.

Кнопка «Добавить в INCY» формирует официальный deep link `incy://import/<subscription-url>`. Если переменная не задана, сайт покажет аккуратный экран ожидания ключа вместо нерабочей ссылки.
